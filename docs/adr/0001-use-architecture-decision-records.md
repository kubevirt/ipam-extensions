# 1. Use Architecture Decision Records

Date: 2026-04-24

## Status

Accepted

## Context

We need to record significant architectural decisions made in this project to help
current and future contributors understand the rationale behind key design choices.

## Decision

We will use Architecture Decision Records (ADRs) as described by Michael Nygard.
ADRs are stored in `docs/adr/` and numbered sequentially.

## Consequences

- Architectural decisions are documented with context and rationale
- Future contributors can understand why specific approaches were chosen
- ADRs are lightweight and version-controlled alongside the code
